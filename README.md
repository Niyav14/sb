☕ Starbucks Beverage Analysis Dashboard

An interactive Starbucks Beverage Analysis Dashboard developed using Microsoft Power BI to explore beverage nutrition, calorie levels, caffeine content, and beverage category distribution.

📊 Dashboard Overview

The dashboard provides a visual analysis of Starbucks beverages through multiple KPIs and interactive charts.

🔑 Key Metrics
Total Calories: 47K
Total Sugar: 8K
Total Sodium: 2K
Total Protein: 1.69K
📈 Visualizations Included
Sum of Calories – Overall calorie analysis
Beverage Category Distribution – Distribution across beverage preparation categories
Calories by Beverage Category – Comparison of calories across categories
Calories by Beverage – Identifies beverages contributing the highest calories
Caffeine Analysis – Compares caffeine counts across beverage categories
Interactive Beverage Category Filter – Allows users to explore specific categories
🛠️ Tools Used
Microsoft Power BI
Data Cleaning & Transformation
Data Visualization
Dashboard Design
Business Intelligence
🎯 Objective

The main objective of this project is to transform Starbucks beverage data into meaningful visual insights that make it easier to understand nutrition content, calorie distribution, beverage categories, and caffeine patterns.

💡 Key Insights

The dashboard helps users identify:

Beverages with higher calorie contributions
Differences in nutritional content
Beverage categories with higher caffeine counts
Overall calorie and nutritional patterns
Distribution of different beverage preparations
🚀 Conclusion

This project demonstrates how Power BI can transform raw beverage data into an interactive analytical dashboard, making complex nutritional information easier to explore and understand.
